# Image library

Finished brand images that aren't tied to one place yet. Browse here when you need a picture for an ad, a post, a page or an email. Sophie started this folder on 2026-11-23.

**Rules for adding:**
- Use a JPG at full resolution, quality ~88. Large PNG originals stay on the local machine only.
- Use a short English file name that says what's in the picture.
- Add one line to the table below.
- Before adding, check the image against the Find Your Bearings rule: never a cube, ladder, lion, road, sea, house or horse.
