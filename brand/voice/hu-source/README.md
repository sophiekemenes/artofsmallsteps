# Sophie's voice — Hungarian source material

**Status: not yet localized.** These four files are the Hungarian-language voice reference for Sophie (Kemenes Andrea Sophie). Per Sophie: this is provided as a knowledge base, not as text to auto-translate. The English voice for Art of Small Steps should be built *together with Sophie*, using these as grounding — not by mechanically translating the Hungarian editorial rules into English equivalents.

## Files

- `SOPHIE-HANGJA.md` — the operational editorial style guide (v2), distilled from the Kincsestérkép/Újratervezés workbook (warm, coach register) and a raw LinkedIn post (rawer, professional register). Defines register-independent principles, the two registers, an AI-tell scan list, and an editing protocol.
- `Sophie_hangja_AI_editori_kezikonyv.md` — an earlier/parallel version of the same editorial handbook, more example-heavy.
- `SOPHIE-ESSENCE-NOTES.md` — already in English: a discursive personal reflection (not a rulebook) on *why* the patterns in the style guide exist, written after reading the full Újratervezés workbook plus a real LinkedIn crisis post. This is the most useful single file for understanding Sophie's voice at a "why" level rather than a checklist level.
- `linkedin-poszt-pelda-2026-08.txt` — a real, raw LinkedIn post by Sophie (August 2026), used as primary source material for the "professional/raw register" in the style guide.

## Core principle carried across all four

> **Don't make it prettier. Make it truer.**
> **Don't remove the strangeness. Find out what it's doing.**

The AI's role when writing "as Sophie" is editor, not copywriter: surface what's already alive in a rough draft, don't launder it into generic marketing register.

## Two registers identified (Hungarian originals)

1. **Kincsestérkép / customer voice** — warmer, coach-like, self-ironic but not self-pitying, playful. Used for training emails, landing pages, product copy.
2. **Professional / personal-brand voice** — rawer, more extreme, willing to be blunt or profane, not a "LinkedIn influencer" register. Used for LinkedIn posts and personal-brand content.

Which (if either, or some third register) applies to Art of Small Steps is an open question — see the main conversation/brand-concept notes, not yet decided here.
